# 宏观经济分析功能 BDD 需求文档

## 一、Epic 故事

### 1. 宏观业务目标

建立"宏观经济分析"能力，为两类使用者提供标准化、可追溯、可对比的经济体周期判定服务：

- **个人投资者**：快速获取标准化的经济周期判定结论，辅助大类资产配置与行业择时决策。
- **专业研究人员**：获得可追溯、可对比的周期判定研究记录，作为撰写研报与投研复盘的素材。

两类角色共用同一份分析结果。

### 2. 模块规划

| 模块 | 本期范围 |
| --- | --- |
| Web 左侧菜单栏"宏观经济分析"栏目 | 新增栏目；栏目内展示提示词 a / b / c，每个提示词旁有"编辑"入口；点击提示词展示对应分析历史 |
| 提示词 a：宏观经济周期判定 | 本期完整实现：选择经济体 → 生成标准化周期判定 → 结果存档与展示 |
| 提示词 b / c | 预留栏目位，可见但暂不可点击，后续补充定义 |
| 提示词编辑 | 本期仅支持编辑提示词正文，仅管理员可操作 |
| AI 工具编排调用流程定义 | 预留扩展入口，本期仅展示、不可配置，后续支持自定义工具及调用顺序 |
| 智能体页面"宏观分析"模块 | 在智能体页面（A 股回测模块旁）新增宏观分析模块，展示 a 提示词入口，点击后调用 AI 完成分析 |

### 3. 核心业务主流程

```
使用者进入宏观经济分析栏目
        │
        ▼
选择预设经济体（中国 / 美国 / 日本 / 欧元区 等）
        │
        ▼
系统判断该经济体最新可得数据月份
        │
        ├── 数据不足 ──▶ 提示数据不足，使用者补充说明或指定数据截止月份后再发起
        │
        ▼
该经济体当月是否已有判定结果？
        │
        ├── 是 ──▶ 直接展示历史判定结果（不重复生成）
        │
        └── 否 ──▶ 点击 a 提示词发起分析（生成中禁止重复发起）
                        │
                        ▼
                 AI 按标准结构输出结论
                        │
                 ├── 输出不合规 ──▶ 自动重试 1 次；仍失败则提示失败、不留存结果
                 └── 输出合规 ──▶ 结论存档 ──▶ 分层展示结果
```

## 二、用户故事与 BDD 验收用例

### 用户故事 1：栏目入口与提示词浏览

**作为** 使用者，**我希望** 在 Web 左侧菜单栏看到"宏观经济分析"栏目，进入后能看到 a / b / c 三个提示词及其编辑入口，**以便** 我清楚有哪些宏观分析能力、从哪里进入。

```gherkin
Feature: 宏观经济分析栏目入口
  Scenario: 使用者从左侧菜单进入宏观经济分析栏目
    Given 使用者已进入系统主界面
    When 使用者点击左侧菜单栏的"宏观经济分析"栏目
    Then 页面展示三个提示词条目，分别为"a 宏观经济周期判定""b 待扩展""c 待扩展"
    And 每个提示词条目旁均展示"编辑"入口
    And 提示词 a 处于可点击状态，提示词 b 和 c 展示为"敬请期待"的不可点击状态

  Scenario: 点击提示词查看其分析历史
    Given 使用者处于宏观经济分析栏目页面
    When 使用者点击提示词 a
    Then 页面进入 a 的分析历史浏览区域
    And 历史按"先选经济体、再看月份时间线"的方式组织
```

### 用户故事 2：选择经济体并发起周期判定

**作为** 个人投资者，**我希望** 在智能体页面的宏观分析模块中点击 a 提示词、从预设清单中选择一个经济体后，快速获得该经济体最新月份的标准化周期判定结论，**以便** 辅助我的资产配置与择时决策。

```gherkin
Feature: 发起宏观经济周期判定
  Scenario: 选择经济体后成功生成当月周期判定
    Given 使用者位于智能体页面，且"宏观分析"模块展示在"A 股回测"模块旁
    And 宏观分析模块中可见提示词入口"a 宏观经济周期判定"
    When 使用者点击提示词 a 并从预设经济体清单中选择"中国"
    And 系统识别出中国宏观数据的最新可得月份为当前待分析月份
    And 该经济体在该月份尚无判定结果
    Then 系统调用 AI 按标准化周期判定提示词执行分析
    And AI 输出结构合规的结论性内容
    And 系统将结论留存为该经济体该月份的判定结果
    And 页面以"结论优先、分层展开"方式展示完整判定结果

  Scenario: 预设经济体清单范围
    Given 使用者打开经济体选择清单
    Then 清单至少包含"中国、美国、日本、欧元区"
    And 使用者只能从预设清单中选择，不能直接输入未在清单内的经济体
```

### 用户故事 3：同月结果不重复生成

**作为** 专业研究人员，**我希望** 同一经济体同一月份只保留并展示一份判定结果，当月已有时直接读取历史结果，**以便** 研究口径一致、不被重复结论干扰。

```gherkin
Feature: 同月结果唯一性
  Scenario: 当月已有结果时直接展示历史结果
    Given 经济体"中国"在最新数据月份"2026-08"已存在一份周期判定结果
    When 使用者选择"中国"并再次点击提示词 a
    Then 系统不重新调用 AI 生成
    And 直接展示 2026-08 的历史判定结果
    And 页面明确提示该结果为当月已有分析结果

  Scenario: 历史月份结果同样唯一
    Given 经济体"日本"在"2026-05"已存在判定结果
    When 使用者浏览到该月份记录
    Then 每个经济体每个月份仅对应一条判定结果
```

### 用户故事 4：分析生成中的防重复与状态反馈

**作为** 使用者，**我希望** 在分析生成期间看到明确的"生成中"状态且不能重复发起，**以便** 避免产生重复结果并知道系统正在处理。

```gherkin
Feature: 生成中状态与防重复
  Scenario: 生成过程中再次点击
    Given 经济体"美国"当月的周期判定正在生成中
    When 使用者再次点击提示词 a 或重复选择该经济体发起分析
    Then 系统阻止再次发起
    And 页面提示"分析生成中，请稍候"

  Scenario: 生成超时
    Given 某经济体的周期判定请求超过可接受等待时长仍未返回
    When 系统判定本次生成超时
    Then 页面提示"分析超时，请稍后重试"
    And 系统不留存本次结果、不产生重复记录
    And 使用者可在稍后重新发起
```

### 用户故事 5：AI 输出不合规时自动重试

**作为** 使用者，**我希望** AI 偶尔输出不规范内容时系统能自动纠正一次，**以便** 尽量让我一次操作就能得到可用结论。

```gherkin
Feature: 输出合规性校验与重试
  Scenario: 首次输出含多余文字，重试后合规
    Given AI 首次返回的内容夹杂解释性文字、无法直接作为规范结论留存
    When 系统检测到输出不符合约定的结构与字段要求
    Then 系统自动要求 AI 按规范重新输出，且仅重试 1 次
    And 重试输出合规时，正常留存并展示结果

  Scenario: 重试后仍不合规
    Given AI 首次输出不合规，且自动重试 1 次后仍不合规
    When 系统确认两次输出均无法采用
    Then 系统不留存任何结果
    And 页面提示"分析失败，请稍后重试"

  Scenario: 周期阶段表述不标准视为不合规
    Given AI 输出的周期阶段未使用"衰退期/复苏期/过热期/滞胀期"标准表述
    When 系统进行合规性校验
    Then 该次输出判定为不合规并触发自动重试流程
```

### 用户故事 6：宏观数据不足时补充后发起

**作为** 使用者，**当** 某经济体宏观数据不足以识别最新月份或支撑分析时，**我希望** 可以补充说明或自行指定数据截止月份后再发起，**以便** 在数据不完整时仍能获得有参考价值的判定。

```gherkin
Feature: 数据不足的处理
  Scenario: 数据不足时先提示再补充
    Given 所选经济体的宏观数据不足以确定最新可得数据月份，或不足以支撑周期判定
    When 使用者选择该经济体并尝试发起分析
    Then 系统暂不调用 AI
    And 页面明确提示"该经济体当前宏观数据不足，暂无法分析"
    And 提供"补充说明"与"指定数据截止月份"两种继续方式

  Scenario: 使用者补充后成功发起
    Given 系统已提示某经济体数据不足
    When 使用者填写补充说明，或将数据截止月份指定为某一历史月份
    Then 系统按补充后的条件调用 AI 执行分析
    And AI 将不确定、待补充的内容统一写入结论中的"扩展备注"
    And 系统允许 AI 据此给出较低的判定置信度
```

### 用户故事 7：按经济体分组浏览分析历史

**作为** 专业研究人员，**我希望** 先选择经济体、再按月份时间线浏览其历次判定，并点开某月查看完整详情，**以便** 做跨周期的对比研究与复盘。

```gherkin
Feature: 分析历史浏览
  Scenario: 按经济体查看月度时间线
    Given 宏观经济分析栏目中已存在多个经济体的历史判定结果
    When 使用者在提示词 a 的历史区域选择经济体"中国"
    Then 页面按月份时间线展示中国的历次判定结果
    And 每条记录至少展示数据月份、周期阶段与判定置信度
    And 时间线按月份由近到远排列

  Scenario: 从时间线进入详情
    Given 使用者正在查看"中国"的月份时间线
    When 使用者点击某一月份记录
    Then 页面展示该月份判定的完整详情
```

### 用户故事 8：判定结果详情分层展示

**作为** 使用者，**我希望** 详情页先看到结论、再按需查看依据，**以便** 投资者快速抓结论、研究人员深入看依据。

```gherkin
Feature: 判定结果详情展示
  Scenario: 结论优先分层展开
    Given 使用者打开某经济体某月份的判定详情
    Then 页面顶部突出展示：经济体名称、数据截止月份、当前周期阶段、判定置信度
    And 顶部下方依次分区展示：判定结果、维度校验、中观验证、历史周期锚定、核心支撑、核心风险
    And "扩展备注"区域默认折叠，使用者点击后展开查看

  Scenario: 置信度展示
    Given 某次判定的置信度为"高/中/低"之一
    When 详情页渲染顶部结论区
    Then 置信度以"高""中"或"低"明确展示，可附带置信区间说明文字
```

### 用户故事 9：管理员编辑提示词正文

**作为** 管理员，**我希望** 能修改提示词 a 的正文内容，**以便** 在标准化结构不变的前提下优化分析口径。

```gherkin
Feature: 提示词编辑与权限
  Scenario: 管理员成功编辑提示词 a
    Given 当前使用者具备管理员身份
    When 使用者点击提示词 a 旁的"编辑"入口并修改提示词正文后保存
    Then 系统留存修改后的提示词正文
    And 后续新发起的分析使用修改后的提示词
    And 已留存的历史判定结果不因提示词修改而变化

  Scenario: 非管理员无法编辑
    Given 当前使用者为普通使用者（个人投资者或研究人员）
    When 使用者尝试点击"编辑"入口
    Then 系统不允许修改提示词
    And 普通使用者仍可正常查看分析结果与全部历史

  Scenario: 工具编排入口本期不可配置
    Given 使用者在提示词旁看到"AI 工具编排调用流程"相关入口
    When 使用者尝试进入配置
    Then 本期仅展示该入口的预留形态，不提供实际配置能力
    And 页面提示该能力将在后续开放
```

### 用户故事 10：预留提示词 b / c

**作为** 使用者，**我希望** 在栏目中看到 b / c 两个待扩展提示词位，**以便** 我了解宏观分析能力的后续规划。

```gherkin
Feature: 预留提示词展示
  Scenario: b / c 暂不可用
    Given 宏观经济分析栏目展示提示词 a、b、c
    When 使用者点击提示词 b 或 c
    Then 系统不发起任何分析
    And 页面提示该分析能力将在后续版本提供
```

## 三、业务与计算规则

### 1. 周期阶段标准表述

- 周期阶段仅允许使用四种标准表述：**衰退期、复苏期、过热期、滞胀期**。
- 允许在标准表述基础上补充过渡阶段描述（如"复苏期向过热期过渡"），但核心判定必须落在四阶段之一。
- 凡未使用标准表述的输出，一律视为不合规输出并触发重试。

### 2. 判定结论的内容构成

每次周期判定结论必须且仅包含以下十项结论性内容，不单独存储零散数字：

1. **经济体**：经济体名称，如中国、日本。
2. **数据截止月份**：格式为"年-月"。
3. **当前周期**：最终判定的经济周期阶段及核心特征。
4. **判定结果**：增长、通胀、货币、信用四维组合的核心结论与周期定位。
5. **维度校验**：增长、通胀、货币、信用四个维度的方向判定与核心依据。
6. **中观验证**：库存周期、产能周期与宏观周期的共振校验结论。
7. **历史周期锚定**：匹配的历史周期区间、匹配度、核心差异点。
8. **判定置信度**：仅取"高 / 中 / 低"，可补充置信区间说明。
9. **核心支撑**：支撑本次周期判定的核心指标与逻辑。
10. **核心风险**：周期判定的背离风险与不确定性因素。

所有不确定、待补充、非结构化的内容，统一归入 **扩展备注**，不在其他字段中零散出现。

### 3. 分析对象与月份规则

- 经济体只能从预设清单中选择，首期清单至少包含：中国、美国、日本、欧元区。
- 每次分析默认采用该经济体**最新可得数据月份**，使用者无需手动选择月份。
- 仅在系统判定数据不足时，才允许使用者通过补充说明或指定数据截止月份继续。

### 4. 唯一性与复用规则

- 判定结果以"经济体 + 数据截止月份"为唯一业务口径，同一经济体同一月份只保留并展示一份结果。
- 当月已有结果时，任何发起动作均直接读取并展示历史结果，不再重新生成。
- 分析生成期间对同一经济体的重复发起动作一律阻止。

### 5. 输出合规与重试规则

- 系统对 AI 输出做结构完整性、字段完整性、周期阶段表述规范性校验。
- 不合规时自动重试 **恰好 1 次**；重试仍不合规则判定为分析失败。
- 分析失败不留存任何结果，仅向使用者展示失败提示。
- 生成超时等同分析失败处理：不留存、不重复，允许稍后重新发起。

### 6. 提示词与编排规则

- 提示词 a 为系统内置标准化提示词，其输出结构（十项结论内容）不得因编辑而改变。
- 本期"编辑"仅允许调整提示词正文；编辑后仅影响后续新发起的分析，历史结果保持不变。
- AI 工具编排调用流程（使用哪些工具、调用先后顺序）为后续扩展能力，本期不开放配置，但在信息架构上预留位置。

## 五、数据管理规则

### 1. 留存策略

- 宏观周期判定结果**永久保留**，不做自动清理或删除。
- 每个经济体每个月的结果长期沉淀，形成完整的周期研究档案，支撑跨周期对比与复盘。
- 历史结果一经生成不因提示词调整而改变；提示词调整只作用于调整后新发起的分析。

### 2. 唯一性与去重

- 以"经济体 + 数据截止月份"作为结果唯一性口径。
- 同口径结果已有记录时直接复用展示，禁止重复生成、重复留存。
- 生成中、超时、失败的请求均不产生正式记录。

### 3. 权限策略

| 角色 | 查看结果与历史 | 发起分析 | 编辑提示词正文 | 配置工具编排 |
| --- | --- | --- | --- | --- |
| 个人投资者 | 允许 | 允许 | 禁止 | 本期不开放 |
| 专业研究人员 | 允许（含完整判定依据） | 允许 | 禁止 | 本期不开放 |
| 管理员 | 允许 | 允许 | 允许（仅提示词 a 正文） | 本期不开放 |

## 六、业务术语表

| 术语 | 定义 |
| --- | --- |
| 经济周期阶段 | 对经济体所处周期位置的标准化归类，仅含衰退期、复苏期、过热期、滞胀期四类，可附过渡阶段描述 |
| 衰退期 | 增长下行、总体需求疲弱的周期阶段 |
| 复苏期 | 增长由底部回升、经济活动逐步恢复的周期阶段 |
| 过热期 | 增长强劲并伴随通胀压力上行的周期阶段 |
| 滞胀期 | 增长下行与通胀高企并存的周期阶段 |
| 四维校验 | 从增长、通胀、货币、信用四个维度对周期位置进行的方向判定与交叉验证 |
| 中观验证 | 以库存周期、产能周期等中观层面周期与宏观周期进行的共振校验 |
| 历史周期锚定 | 将当前周期特征与历史周期区间进行匹配，给出匹配度与核心差异点 |
| 判定置信度 | 对本次周期判定可靠程度的结论性评级，仅取高、中、低三档，可附置信区间说明 |
| 核心支撑 | 支撑本次周期判定的核心指标与逻辑链条 |
| 核心风险 | 可能导致周期判定失效的背离信号与不确定性因素 |
| 扩展备注 | 统一存放所有不确定、待补充、非结构化内容的结论性栏目 |
| 最新可得数据月份 | 系统按经济体宏观数据实际覆盖情况识别出的最新数据截止月份（年-月） |
| 预设经济体清单 | 系统固定提供的可选分析对象集合，首期至少含中国、美国、日本、欧元区 |
| 提示词 a / b / c | 栏目内三个宏观分析提示词槽位；本期仅 a（宏观经济周期判定）可用，b / c 预留 |
| 工具编排调用流程 | 对一次分析中 AI 调用哪些工具、以何种先后顺序调用的流程定义能力，本期预留、后续开放 |
