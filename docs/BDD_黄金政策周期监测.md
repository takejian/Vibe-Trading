# BDD 需求文档 — 黄金政策周期监测模块

> 面向个人黄金投资者的金价与美联储利率周期关联监测功能

---

## 一、Epic Stories

### Epic 1：黄金宏观状态实时感知
为个人黄金投资者提供金价、联邦基金利率、美债收益率等核心宏观指标的月度快照，让用户在一个页面上一目了然地看到当前市场状态及其近12个月走势，辅助判断黄金的估值高低。

### Epic 2：美联储政策周期识别与标注
将1996年至今的历史月份按美联储政策阶段（加息周期 / 降息周期 / 利率平台）进行划分和标注，新的政策周期由系统根据联邦基金利率变动方向自动判定，但切换边界需用户审核确认后方可生效。

### Epic 3：历史周期回溯与学习
以政策周期为单位组织全部历史月度数据，用户可点击任一周期查看该周期内每个月的完整指标明细，用于复盘利率与金价在不同政策环境下的联动规律。

### Epic 4：数据自动维护与质量保障
每月1号自动刷新上月完整数据并存入本地；手动刷新提供一次主动获取能力；所有新进入的数据都要与已存储值做一致性校验，发现差异时提示用户确认。

---

## 二、User Stories

### US-01：查看当前黄金宏观状态卡片

> **As a** 个人黄金投资者
> **I want to** 在进入黄金页面时，看到当前月份的7个核心宏观指标卡片，每个卡片同时显示当前值和近12个月迷你走势图
> **So that** 我能快速判断金价在当前利率环境下的大致位置和趋势方向

#### BDD 验收用例

```gherkin
Feature: 当前状态页面展示

  Scenario: 用户首次进入黄金当前状态tab
    Given 本地数据表中已存在至少一个月的历史数据
    When 用户点击左侧"黄金"菜单项并停留在当前状态tab
    Then 页面左上角应显示当前月份所属的政策周期名称
    And 页面主体应展示7张指标卡片，每张卡片包含指标名称、当前值、单位、近12个月迷你折线图
    And 若迷你折线覆盖的月份不足12个月，则按实际可用月数展示

  Scenario: 当前月份数据在本地尚未存储
    Given 本地数据表最新月份早于当前月份
    When 用户进入黄金当前状态tab
    Then 页面应提示"本月数据尚未更新，是否立即刷新"
    And 已存储的最新月份数据正常展示为当前快照

  Scenario: 2003年之前的历史月份缺少实际利率数据
    Given 当前选中的是2003年之前的某个月份
    When 页面加载该月份指标
    Then 10年期TIPS实际利率卡片显示"N/A"
    And 该卡片下方显示提示文字"TIPS数据自2003年起可用"
```

### US-02：识别并展示当前政策周期

> **As a** 个人黄金投资者
> **I want to** 在当前状态页面左上角看到明确的政策周期标签（如"2024-09~至今 新一轮降息周期"）
> **So that** 我能瞬间知道美联储当前是在加息、降息还是按兵不动

#### BDD 验收用例

```gherkin
Feature: 政策周期自动判定

  Scenario: 当前月份落在历史预设周期内
    Given 当前月份已存在于历史政策周期划分表中
    When 页面加载当前状态
    Then 左上角政策周期标签应显示该预设周期的起、止月份和周期名称

  Scenario: 当前月份超出所有历史预设周期，需系统自动判定
    Given 当前月份晚于历史预设周期的最后一个月
    And 近3个月联邦基金利率连续上升
    When 页面加载当前状态
    Then 系统应自动将当前月份归入"加息周期"
    And 新周期的起始月份应为利率首次连续变动的那个月
    And 该新周期进入"待审核"状态，页面右上角显示审核提示

  Scenario: 用户审核确认新识别的政策周期
    Given 存在一个"待审核"的新政策周期
    When 用户点击审核提示并确认周期起止和名称
    Then 该周期状态变为"已生效"
    And 历史tab中同步显示该周期

  Scenario: 联邦基金利率连续多月无明显变动
    Given 近3个月联邦基金利率变动幅度均小于等于0.05个百分点
    When 系统判定当前政策阶段
    Then 应标记为"利率平台"而非加息或降息周期
```

### US-03：手动刷新当前数据

> **As a** 个人黄金投资者
> **I want to** 在当前状态页面点击"刷新"按钮，主动获取最新月份数据
> **So that** 当我认为数据可能滞后时，可以随时拉取最新快照

#### BDD 验收用例

```gherkin
Feature: 手动刷新数据

  Scenario: 用户点击刷新按钮，大模型成功返回新月份数据
    Given 用户停留在黄金当前状态tab
    And 本地最新数据月份为2026-09
    When 用户点击"手动刷新"按钮
    And 大模型成功返回2026-10的7个指标值
    Then 页面展示应立即更新为2026-10的数据
    And 本地数据表中新增一条2026-10记录
    And 若自动判定出新政策周期则进入待审核状态

  Scenario: 大模型返回的数据与本地已存储数据存在差异
    Given 本地已存储2026-09金价为4319
    When 用户点击刷新，大模型返回2026-09金价为4350
    Then 页面应弹出确认弹窗，展示"本地值 vs 新获取值"的对比
    And 用户确认后才覆盖本地数据
    And 用户拒绝则保留原数据不变

  Scenario: 当前月份官方数据尚未发布
    Given 当前日期在1-3日之间，上月官方数据尚未发布
    When 用户点击刷新
    And 大模型返回"数据尚未发布"的响应
    Then 页面应保留本地上次数据
    And 在刷新按钮旁显示"数据尚未发布，将保留上月快照"的提示

  Scenario: 大模型获取失败或返回字段不全
    Given 用户点击刷新按钮
    And 大模型请求超时或部分字段缺失
    Then 页面顶部应显示明显的红色/橙色提示条
    And 提示条内容为"刷新失败，数据可能不是最新"
    And 保留本地上次数据显示
    And 提示条上提供"重试"按钮
```

### US-04：每月自动刷新上月数据

> **As a** 个人黄金投资者
> **I want to** 每月1号系统自动拉取并存储上月完整数据，无需我每次手动操作
> **So that** 我打开页面时数据总是最新的，不会因为忘记刷新而看到过期信息

#### BDD 验收用例

```gherkin
Feature: 每月自动定时刷新

  Scenario: 每月1号定时任务正常执行
    Given 今天是某月1号
    And 上月数据尚未存入本地
    When 定时任务自动触发
    And 大模型成功返回上月数据
    Then 本地数据表应新增上月记录
    And 自动判定政策周期（若有切换）

  Scenario: 定时任务执行失败
    Given 今天是某月1号
    And 定时任务执行时大模型调用失败
    When 用户在5号打开黄金页面
    Then 页面应主动提示"上月数据尚未更新，是否立即刷新"
    And 用户点击后触发手动刷新流程

  Scenario: 定时任务返回数据与本地不一致
    Given 定时任务拉取的数据与本地已存储的同月数据有差异
    When 定时任务执行完毕
    Then 页面在下次被访问时应提示用户进行确认
    And 待用户确认后才执行覆盖
```

### US-05：查看历史政策周期与月度明细

> **As a** 个人黄金投资者
> **I want to** 在历史tab看到所有政策周期列表，点击任一周期可展开查看该周期内每个月的指标明细表格
> **So that** 我能复盘历史上不同政策阶段下金价的表现规律，为当前决策提供参考

#### BDD 验收用例

```gherkin
Feature: 历史周期查看

  Scenario: 用户打开历史tab
    Given 本地数据表中已存在1996-10至今的历史数据
    When 用户切换到历史tab
    Then 应显示所有历史政策周期的列表，每个周期显示起、止月份、月数、周期名称、金价期初值、金价期末值、金价涨跌幅
    And 最新的"已生效"周期排在列表最上方

  Scenario: 用户点击某个历史周期展开月度明细
    Given 历史tab已展示周期列表
    When 用户点击"2001-01~2004-06 降息周期"
    Then 该周期下方展开一个月度明细表格

    And 每一行对应该周期内的一个月份，按时间升序排列

  Scenario: 展开的周期跨越2003年，部分月份缺少TIPS数据
    Given 用户点击的周期同时覆盖2002年和2004年的月份
    When 月度明细表格展开
    Then 2003年之前的月份在"TIPS实际利率"和"实际利率月度变动"两列显示"N/A"
    And 表格底部显示注释："注：10年期TIPS实际利率数据自2003年起可用，之前月份标记为N/A"

  Scenario: 用户点击"待审核"状态的周期
    Given 历史tab中存在一个"待审核"的新周期
    When 用户点击该周期
    Then 页面应先弹出审核对话框
    And 用户确认后才展开月度明细
```

## 三、业务/计算规则

### R1：10年期TIPS实际利率计算
> 10年期TIPS实际利率 = 10年期美债名义利率 − 10年期盈亏平衡通胀率 BEI
>
> 说明：名义利率与 BEI 同期可得时按此公式计算；若 BEI 缺失（2003 年之前），则该月实际利率记为 N/A。

### R2：金价环比涨跌计算
> 金价环比涨跌 = (本月金价 − 上月金价) ÷ 上月金价 × 100%
>
> 结果保留两位小数，正为上涨（绿色），负为下跌（红色）。

### R3：利率月度变动计算
> 政策利率月度变动 = 本月联邦基金利率 − 上月联邦基金利率（单位：pct 点）
> 实际利率月度变动 = 本月实际利率 − 上月实际利率（单位：pct 点）
>
> 结果保留两位小数，正为上升（绿色），负为下降（红色）。

### R4：政策周期自动判定规则（用于未来新周期）
> 判定粒度为月度。当满足以下任一条件时，标记一个新周期的起点：
>
> - 加息周期起点：连续两个月联邦基金利率上升幅度均 > 0.05 pct 点，且之前处于降息或平台期
> - 降息周期起点：连续两个月联邦基金利率下降幅度均 > 0.05 pct 点，且之前处于加息或平台期
> - 平台期起点：连续两个月联邦基金利率变动幅度均 ≤ 0.05 pct 点，且之前处于加息或降息周期
>
> 每个周期的名称建议格式：`起始月 ~ 至今/结束月  （加息周期 / 降息周期 / 利率平台）`
>
> 注：自动识别出的新周期进入"待审核"状态，用户确认后方可正式生效。

### R5：数据刷新一致性校验
> 每次刷新获得新数据后，对每个已存在月份执行以下校验：
>
> - 若该月在本地尚不存在：直接入库，记录为"新增"
> - 若该月已在本地存储且所有字段值一致：无操作，提示无需更新
> - 若该月已在本地存储但至少一个字段值有差异：弹出确认，展示各字段"本地值 vs 新值"，用户确认后覆盖，拒绝则保留原值

### R6：数据版本策略
> 月度数据表仅保留每个月份的最新值，刷新时直接覆盖，不保留历史修订版本。

### R7：定时触发时间
> 每月1号触发自动刷新，拉取上一个自然月的完整数据。

## 五、数据管理规则

### D1：数据表结构
系统维护两张本地数据表：
- **月度指标表**：主键为 (月份)，存储7个核心指标值 + BEI原始值 + 更新时间戳
- **政策周期表**：主键为 (周期ID)，存储周期名称、起止月份、周期类型（加息 / 降息 / 平台）、状态（已生效 / 待审核）

### D2：数据来源
- **历史初始数据**：首次部署时从用户提供的历史月度数据导入（覆盖1996-10 至 当前已完成月份）
- **后续增量数据**：通过大模型调用预先配置的提示词获取，每月1号自动触发、支持手动触发
- **历史政策周期**：首次部署时按用户提供的历史政策周期划分表直接导入

### D3：数据一致性保障
- 每次大模型返回数据后都执行 R5 定义的一致性校验
- 定时任务触发的数据差异在下次页面访问时提示
- 大模型调用失败或返回字段不全时，不写入数据表，仅保留原有值

### D4：数据可追溯性
虽然同一月份仅保留最新值，但每次刷新都会记录该次调用的来源摘要（成功 / 失败、返回字段完整度），供排查问题。

### D5：政策周期审核
- 自动识别的新周期默认进入"待审核"状态
- 待审核周期不参与当前状态tab的自动展示逻辑
- 用户确认后变为"已生效"，立即对当前状态和历史tab生效

## 六、业务术语表

| 术语 | 定义 |
|------|------|
| 金价（月均） | 国际金价月度平均价格，单位美元/盎司 |
| 联邦基金利率（FFR） | 美国银行间隔夜拆借的实际有效利率，是美联储货币政策的核心操作目标 |
| 名义利率 | 10年期美国国债的市场收益率，未剔除通胀预期 |
| 盈亏平衡通胀率（BEI） | 10年期名义利率与10年期TIPS收益率之差，代表市场对未来通胀的预期 |
| TIPS实际利率 | 10年期通胀保值国债（TIPS）的收益率，已剔除通胀预期；等于名义利率减BEI |
| 加息周期 | 美联储连续提高联邦基金利率的阶段，通常伴随金价承压 |
| 降息周期 | 美联储连续降低联邦基金利率的阶段，通常伴随金价上行 |
| 利率平台 | 联邦基金利率连续多月保持稳定（月度变动 ≤ 0.05 pct 点）的阶段 |
| 政策周期 | 由若干连续月份组成的区间，在该区间内美联储维持同一货币政策倾向（加息、降息或平台） |
| Sparkline | 迷你折线图，以极紧凑的空间展示一个指标的近期走势 |
| pct 点 | 百分点，利率变动的计量单位，1 pct 点 = 1% |
